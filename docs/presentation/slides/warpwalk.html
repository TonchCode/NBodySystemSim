The main result. Instead of each lane walking its own path, the warp pops one node at a time; every lane does its own opening test, and the warp opens the node if any lane needs it. So the warp walks the union of its 32 paths. The paradox to explain: it does 1.64–1.85× more interactions than #5 (a lane gets children of a node it would have accepted), yet it is 5.8× faster. Because: every instruction runs on all 32 lanes (SIMT efficiency 1.000 instead of 0.20); every node load is one broadcast instead of up to 32 scattered loads (the profiler measured 14× fewer memory sectors); and the stack is 64 entries spread over 2 registers per lane, push = predicated move, pop = one shuffle, no local memory. It adds work and removes incoherence. It is not work stealing. Accuracy: rms error 4.59e-3 vs 6.55e-3 at 262,144, because each lane uses at least the cells it would have used alone. Without the Morton order the union is huge and it is 12.9–14.8× slower: #7 needs #5. Numbers: best vs best at 1M: #5 leaf 32 block 256 34.45 ms; #7 leaf 16 block 64 5.99 ms; 4.8× at 262,144. Rate 321 G interactions/s vs 28.8 for #5. Idea from Burtscher & Pingali 2011 (warp vote); our tree is a Karras binary radix tree instead of an octree with locks.
