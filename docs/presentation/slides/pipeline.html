5

Walk left to right. The classic algorithm inserts bodies one by one, which is sequential; every step here is massively parallel. Step 2: Morton keys. Cut space into a 2^21 grid per axis and interleave the bits of x, y, z. Sorting by that key puts bodies that are close in space next to each other in memory. Slide example: x = 5 (101), y = 3 (011) interleave to 27. Step 4: Karras 2012. For sorted keys, each internal node can find its own range and split point with no help from other nodes, so all N−1 nodes are built at once, without locks. We build a binary tree, not an octree: one kernel, but about 3× deeper. Step 5: each leaf climbs up; at each parent the first child to arrive stops, the second computes the parent. Each node is done exactly once. Step 6 is where all the time goes, so every technique on the next slides is about step 6.
