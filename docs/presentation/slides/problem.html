The problem

Every body pulls on every other body

N

bodies, each with a mass and a position; gravity a ∝ m / r²

N²

interactions per time step if every pair is computed directly

10¹²

interactions per step at N = 1 million

One step = compute every acceleration (the expensive part), then move the bodies with the leapfrog integrator (cheap, O(N)).

2

Say: N bodies, each one feels the gravity of all the others. Computing every pair is N squared; at a million bodies that is a trillion interactions per step. Moving the bodies afterwards is cheap; the force computation is everything. If asked about the integrator: leapfrog (kick-drift-kick), symplectic, so energy stays bounded over long runs.
