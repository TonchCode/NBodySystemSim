This answers "which memory is used for what, and which suits the project best". Rule of thumb: the right place depends on how often a byte is reused. Registers for what each body uses every interaction. Shared memory for the all-pairs tile: one load from VRAM, then all 256 threads read it, so VRAM traffic drops by the block size. The tree cannot go in shared memory (it is far too big), so it lives in VRAM but must be read through L1 and L2; the sort is what makes that work. Local memory is a trap: it is private per thread but physically in VRAM. #5's 384-byte stack lives there; #7 moved it into registers. Constant memory: only kernel parameters, 380–456 bytes. Read-only path: tested for #7, no effect (next section). Latency numbers are from a 2025 microbenchmark paper (Chinese-led, HKUST Guangzhou) on the RTX 4090, the same Ada architecture; our card is not separately measured.
