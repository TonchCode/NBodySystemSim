## 2. How the model now accounts for memory incoherence

Round 1 converted counts into time with an issue-slot model and missed absolute speed by 2–4×,
because the scattered (non-broadcast) loads of a divergent walk cost far more than their issue
slots. This round does not model that cost from first principles. It **measures** it: the coherent
control runs #5's kernel and instruction mix with all lanes coherent, so T5 / TC is the whole
intra-warp penalty (idle lanes + memory incoherence + the divergent stack), without a residual or
a c_V assumption. The predictions then factor #7 as
T5 / T7 = (T5 / TC) × (TC / T7), where:
- **TC / T7** is predicted from the work ratios: a coherent walk is bound by its dependent pop
  chain, so time scales between the pop ratio (V7 / V5 = 1.33 at 8192) and the interaction ratio
  (1.73), central 1.45. This factor is anchored (§0.4: 1.32 at 8192) and narrow.
- **T5 / TC** is the uncertain factor. The model: the coherent walk is latency-bound
  (≈ 1000 cycles per pop step, §0.6) and scales with resident warps until issue or L1 throughput
  binds, while #5 is already throughput-bound on scattered accesses at 26 warps/SM (round 1: its
  rate went 15 → 34 → 29 G/s at 4 / 26 / 48 warps/SM). Predicted control lane-rates: 130 / 170 / 200
  G/s at 65536 / 262144 / 1M (latency hiding of ≈ 26 / 48 / 48 warps at ≈ 1000 cycles per pop,
  derated ≈ 2× for L2 latency growing under load and for issue). The ranges are wide (×/÷ 1.75)
  because that derating is the round-1 failure mode. Set D tests the latency-bound claim directly.

## Post-registration note (2026-10-17, after the phase-2 runs; nothing above was changed)

Scoring readings, fixed while scoring and stated here so they can be checked
(`tools/tree_analysis.py --round2` computes every verdict; `results/2026-10-17_tree_round2/scorecard.csv`):
1. **One ID = one scorecard row.** An ID with several cells (N, IC, metric) is a HIT only if every
   cell is in its range. P2-W14 was registered as "one item per IC x metric" and is scored as the
   four rows P2-W14a-d; P2-W16 (interaction ratios and traversal ratios in one bullet) is one row.
   Result: **39 HIT / 22 MISS of 61 rows.**
2. **Background load.** The session had 20-22% idle GPU utilisation from desktop applications
   (`env_before.txt`, `env_after.txt`). Measured contamination on round-1 reference points:
   +2.4% / +2.7% traversal (`contam/`). Absolute times also drift by up to ~7% between sets (#5,
   1M, leaf 16, block 128: 39.5 ms in set A, 42.2 ms in set C); adjacent-run ratios are stable (set
   A2 spread <= 1.5% except static core, 6.8%). The scorecard's `note` column flags the #6 items as
   load-sensitive; their verdicts do not hinge on it (every #6 arm misses by 5-36%).
3. **`--occ-blocks 12` gave 11 resident blocks** (shared memory is allocated in 256 B granules; the
