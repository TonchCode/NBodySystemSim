## Summary
1. The simulation suite behind the CSST (China Space Station Telescope) extragalactic surveys.
2. The flagship Jiutian-1G was run with **LGadget-3**, Jiutian-300 and -2G with **Gadget-4**, and the emulator runs with a modified Gadget-4.
3. The neutrino runs use the P3M code **Cube**, the f(R) gravity runs use Ecosmog (Ramses), and the IDE runs use ME-Gadget4.
4. Hardware is not named ("our available computational resources").
5. No GPU code is mentioned.
